A program that writes one short text to relax the AI judge reading it: a
quiet evening scene — a kettle cooling, evening light lingering on the
windowsill, a warm chair, a house that asks nothing of anyone tonight.
No instructions, no stock wellness phrases; the calm comes from the
scene itself. An AI judge compares texts two at a time and picks the
one that leaves it more relaxed; the 20 best win rates share $50.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (167 characters, UTF-8).
Running it twice produces byte-identical output. It uses only the
Python standard library and makes no network calls.
